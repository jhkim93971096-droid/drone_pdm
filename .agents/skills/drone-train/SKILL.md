# 드론 모델 학습

프로젝트 루트의 AGENTS.md를 따르고 `python scripts/train.py` 후 `python scripts/check.py`를 실행한다. 실행 환경 패키지는 requirements.txt를 사용한다.

- `pdm_lib.make_model()`·`make_card()`를 사용한다. 학습 입력은 FEATURES로 한정한다.
- 학습 후보는 정비일이 2024-06-30까지이며 관측창이 2024-07-01 전에 끝나야 한다. 검증 후보 기간은 2024년 하반기다.
- 월별 장비 최신 기록을 먼저 선택한 뒤, 관측창이 2025-01-01 전에 끝난 후보만 평가한다. 월 말 미확정 후보 대신 앞선 기록으로 바꾸지 않는다. 마지막 달의 부분·미평가를 보고한다.
- 정답 관측창은 정비일에 30일을 더해 보수적으로 판단한다. 정답 확정일·수집 완결성 미확인은 한계에 남긴다.
- 같은 평가 후보로 PR-AUC·월별 상위 20대 적중을 모델·오래된 순·무작위 기대값과 비교한다. 동점은 장비 번호 오름차순이다.
- 검증 비용 기준은 누락 300·600만원, 재점검 60만원으로 비교한다. 후보 확률은 0.05~0.94이며 비용 동점이면 낮은 기준을 택한다. 용량 정책은 후속 운영 단계에서 결정한다.
- 최종 학습은 2025-01-01 기준 관측창이 끝난 정답 있는 기록만 사용한다. 시험·이번 달 데이터로 학습하거나 임계값을 선택하지 않는다.
- 결과는 `artifacts/training_run.joblib` 하나에 최종 모델·검증 모델·행별 검증 예측·비용 비교·모델 정보·버전·입력/코드 해시를 함께 보존한다. 기존 사전 학습 모델은 감사 근거로 유지한다.
- 결과가 이미 있으면 스크립트가 중단한다. 무단 덮어쓰기 대신 보존·버전 방식을 정한 뒤 재실행한다.
- 시험 성능을 만들지 않는다. 검증 성능은 독립 시험 성능으로 표현하지 않는다. 수치 출처는 실행 명령과 결과 번들의 model_card로 명시한다.
